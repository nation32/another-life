## 생성 방법
- Figma 파일: `jlydaLkMz8kpxaHB8n6SYR` (Figma 커넥터의 `generate_image`)
- 모델: `gemini-3.1-flash-lite-image`, 1024×1280 (세로 4:5)
- 무료 플랜 하루 한도: 약 25장. 한도는 한국시간 오전 9시에 초기화돼요.
- 모든 프롬프트 앞에 붙이는 문장:
  `Korean webtoon / soft anime illustration, single comic panel, clean line art, gentle cel shading, cinematic, vertical 4:5 frame. Absolutely no text, no letters, no numbers, no speech bubbles.`
- 받은 그림은 720px 이하 JPEG(품질 82)로 줄여 `public/img/<파일명>.jpg`에 저장해요.
- `index.html`의 `RIMG_DERMA` / `RIMG_DAERI`에 연결해요. 형식: `장면id: [선택0 파일명, 선택1 파일명, ...]` (그림이 없는 자리는 `null`)
- 연결한 뒤 `npm run build`, 390px 스크린샷으로 확인(ui-self-check), 커밋·푸시.
